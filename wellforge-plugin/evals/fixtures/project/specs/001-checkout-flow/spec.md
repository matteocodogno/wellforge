# Checkout flow

## Problem
Customers cannot pay.

## User stories
- As a customer, I can pay for a basket so that I receive the goods.

## Acceptance criteria
- AC-1: a basket with at least one line can be paid with a valid card.
- AC-2: a declined card leaves the basket intact and shows the issuer's reason.

## Non-goals
- Refunds.
