# Search filters

## Problem
The catalogue list cannot be narrowed, so it is unusable past a hundred items.

## User stories
- As a shopper, I can filter by category and price so that I find things.

## Acceptance criteria
- AC-1: filtering by category narrows the list without a page reload.
- AC-2: an empty result set explains itself and offers to clear the filters.

## Non-goals
- Full-text search.
