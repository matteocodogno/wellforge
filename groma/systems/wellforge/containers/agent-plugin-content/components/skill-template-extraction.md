WellForge template extraction — turn an existing project into (1) a stack profile checked against the shipped presets (the gap check) and (2) an opt-in, org-internal Copier template a team can scaffold its next service from. Use during /wellforge:adopt (Stage 0 always runs profile+gap; extraction is opt-in) and for /wellforge:extract-template.
