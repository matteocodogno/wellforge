WellForge Visual Companion — a browser tool the designer uses during /wellforge:design to show mockups, wireframes, diagrams and side-by-side layouts instead of describing them, capturing the user's clicks. Use ONLY when the designer was invoked interactively with the companion enabled (the `--visual` flag on /wellforge:design); NEVER in a headless or orchestrated run and NEVER in the spike tier.
