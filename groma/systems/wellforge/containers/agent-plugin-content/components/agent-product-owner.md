Product Owner for the WellForge spec-driven workflow. Use to draft or refine a feature specification (specs/NNN-slug/spec.md): problem framing, user stories, acceptance criteria, non-goals. Invoke when starting a new feature, when a spec needs rework after feedback, or as the first stage of the orchestrated pipeline. Trigger phrases: "write the spec for", "act as PO", "define the scope of".
