WellForge terse mode — the token-efficient conversational output cue, orthogonal to rigor tier. Use whenever running /wellforge:spike (terse by default), when /wellforge:orchestrate or /wellforge:implement is given --terse/--no-terse, when the main-loop /wellforge:terse toggle is invoked, or when deciding whether a piece of output should be compressed.
